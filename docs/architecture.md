# Architecture

| Crate | Responsibility |
| --- | --- |
| `agge-core` | Project encoding, typed references, DSL compilation, edit operations, transaction history, and local knowledge |
| `agge-runtime` | Fixed-tick simulation, action input, collision, scene primitives, replay assertions, media loading, and headless PNG capture |
| `agge` | Compact CLI and MCP over stdio, desktop packaging, and shared service handlers |
| `agge-studio` | Native editor, OpenGL rendering, audio output, and the separate desktop player |

The source document is the authority. A sorted, typed resource index feeds validation, reference queries, safe renaming, and the runtime compiler. The manifest hashes canonical resource data, so changes in resource order or JSON spacing are excluded from semantic session deltas. A session checkpoint also hashes each referenced media file once by path. Media lookup shares the same confinement and file-size limits used by the engine and exporter. The base revision encodes 128 bits of the BLAKE3 hash of the source bytes, so optimistic writes still detect edits from outside AGGE. An index is rebuilt when needed, and a session diff uses content fingerprints without recompiling scripts. The parser records event byte ranges and symbol access lines, allowing safe event edits without reconstructing unrelated source.

The store serializes AGGE writers using a sibling lock file. For each commit it writes a journal with the history before and after the edit, then atomically replaces the source. A later writer chooses the matching history by comparing it with the live revision. History keeps up to 12 undo and redo entries per project. Direct source edits establish a new history boundary. The lock, journal, and knowledge files are local sidecars. Commit the project and its relative assets to Git.

Rooms can be larger than the logical viewport. Camera follow uses the same placement index as scoped replay assertions. The camera updates after simulation and resets on room entry, so a headless crop and a native playtest share the same viewport origin at a given simulation tick. Native lighting caches a padded region of the world on a fixed sample grid so ordinary camera motion reuses the texture. HUD labels use viewport coordinates.

The headless simulation consumes input and advances exactly once per tick. Replay sorts input transitions once and reference-counts overlapping spans for each action. The native player times the same simulation using a fixed accumulator. A seeded PRNG drives game randomness and a separate stream drives particle bursts. Collisions and triggers use AABBs. Rendering culls against the view, native textures are cached, and the editor and player use the same room primitives. Tile rows stay compact character grids. A layer shares an atlas through a typed sprite dependency and batches visible textured and flat tiles into separate native meshes. Flat maps and distant tilemap-editor views use a cached texture with one swatch per cell. The headless renderer uses bitmap text and the native renderer uses egui fonts, so their images can differ. Floating-point behavior is tested for repeatability on one build, with cross-architecture bitwise equivalence outside the current contract.

The script compiler resolves local function calls and the project index links qualified calls across scripts. Module references are rewritten by resource rename. The evaluator gives each call its own parameter slots and bounds recursion with the expression nesting limit and tick instruction budget. Runtime faults keep the failing entity for inspection and record the statement line and innermost call frames. Functions currently evaluate numeric expressions. String values and foreign APIs are outside the current scripting model. The resource system supports keyboard actions, HUD labels, basic lighting, single-shot audio, and tile or object collision. Web and mobile players, controller support, visual effects beyond burst particles, and a general-purpose UI system are outside version 0.1. Native runtime performance has yet to be characterized on large production games.
