# Architecture

| Crate | Responsibility |
| --- | --- |
| `agge-core` | Project encoding, typed references, DSL compilation, edit operations, transaction history, and local knowledge |
| `agge-runtime` | Fixed-tick simulation, action input, collision, scene primitives, replay assertions, media loading, and headless PNG capture |
| `agge` | Compact CLI and MCP over stdio, desktop packaging, and shared service handlers |
| `agge-studio` | Native editor, OpenGL rendering with an optional Windows Vulkan build, audio output, and the separate desktop player |

Pixel artwork compiles in core into indexed layers and named poses. Inherited poses share their layer buffers until a command changes one. A bounded resolver validates palette compatibility and caches component renders, and the dependency index traces artwork, styles, and generated sprite sources. Runtime media packs the selected poses into RGBA sheets and shares identical sheets between aliases. The native editor, headless captures, tile atlas, and exporter consume the same frame rectangles. Scoped glyph queries composite only the requested area, and PNG previews can render a candidate transaction against the current source revision.

The source document is the authority. A sorted, typed resource index feeds validation, reference queries, safe renaming, and the runtime compiler. The manifest hashes canonical resource data, so changes in resource order or JSON spacing are excluded from semantic session deltas. A session checkpoint also hashes each referenced media file once by path. Media lookup shares the same confinement and file-size limits used by the engine and exporter. The base revision encodes 128 bits of the BLAKE3 hash of the source bytes, so optimistic writes still detect edits from outside AGGE. An index is rebuilt when needed, and a session diff uses content fingerprints without recompiling scripts. The parser records event byte ranges and symbol access lines, allowing safe event edits without reconstructing unrelated source.

The store serializes AGGE writers using a sibling lock file. For each commit it writes a journal with the history before and after the edit, then atomically replaces the source. A later writer chooses the matching history by comparing it with the live revision. History keeps up to 12 undo and redo entries per project. Direct source edits establish a new history boundary. The lock, journal, and knowledge files are local sidecars. Commit the project and its relative assets to Git.

The service layer batches reads on one immutable store snapshot and builds its dependency index lazily. MCP reuses the parsed project and its index while the source revision matches. It reads and hashes the source again on each query to detect external edits. Guarded edits validate a candidate under the writer lock and pass it to the runtime replay checker before writing. A replay suite compiles once and starts a new world per case. Those worlds share immutable project data, script programs, object definitions, animations, and static tile collision. A failed guard or preview creates no history entry.

Studio playback and headless verification drive the same stepwise replay runner. It applies recorded input, ticks the world, and evaluates assertions and samples before the native renderer plays any queued audio. Studio can pause and inspect that world between ticks.

Action transitions and logical pointer spans share the replay clock. A change watch emits initial values and transitions for selected fields. Unchanged text is compared by reference. A runtime checkpoint stores tick-boundary state against a canonical project fingerprint. Restoring rebuilds spatial indexes and room geometry without running create events. Studio can bind a compatible external edit to the current state after validating the new project and media. The editor and playtest share those indexed resources and sprite buffers.

Rooms can be larger than the logical viewport. Camera follow uses the same placement index as scoped replay assertions. The camera updates after simulation and resets on room entry, so a headless crop and a native playtest share the same viewport origin at a given simulation tick. Native lighting caches a padded region of the world on a fixed sample grid so ordinary camera motion reuses the texture. HUD labels use viewport coordinates.

Solid and one-way instance bounds are indexed in 64-pixel cells. Large colliders and wide sweeps have bounded fallback paths. Axis clamping is independent of candidate order, so bucket membership can change as instances move without changing deterministic collision results. Tests compare the indexed path with an exhaustive sweep. Studio and the runtime share the replay format, including action spans captured before each native simulation tick.

Overlap checks use the same spatial index, with a separate set of buckets for each object type referenced by a compiled `touch` expression. The query stops at the first actual bounds overlap. The runtime updates membership after each actor runs, so scripts observe the same positions and lifetimes as the tick's established execution order.

Actors without a step event, gravity, velocity, or active timers stay in the room and collision indexes without being removed and reinserted every tick. Create events still run for all placements, and a create event that sets velocity makes its actor eligible for movement and velocity collision events.

Tile collision compiles to one occupancy bit per cell for maps that actually contain blockers. The render palette remains independent of collision. Instance timer and animation overrides allocate only for actors that use them. Native and headless rendering share depth ordering and HUD primitives. Sprite resources that point to the same PNG share one decoded buffer. Media validation uses a bounded read and checks that audio yields decoded samples at its start through the same codecs used by native playback.

The headless simulation consumes input and advances exactly once per tick. Replay sorts input transitions once and reference-counts overlapping spans for each action. The native player times the same simulation using a fixed accumulator. A seeded PRNG drives game randomness and a separate stream drives particle bursts. Collisions and triggers use AABBs. Rendering culls against the view, native textures are cached, and the editor and player use the same room primitives. Tile rows stay compact character grids. A layer shares an atlas through a typed sprite dependency and batches visible textured and flat tiles into separate native meshes. Flat maps and distant tilemap-editor views use a cached texture with one swatch per cell. The headless renderer uses bitmap text and the native renderer uses egui fonts, so their images can differ. Floating-point behavior is tested for repeatability on one build, with cross-architecture bitwise equivalence outside the current contract.

The script compiler resolves local function calls and the project index links qualified calls across scripts. Module references are rewritten by resource rename. The evaluator gives each call its own parameter slots and bounds recursion with the expression nesting limit and tick instruction budget. Runtime faults keep the failing entity for inspection and record the statement line and innermost call frames. Functions evaluate numeric expressions. Web and mobile players, controller input, and a general-purpose UI system are outside version 0.1. The timing harness measures isolated workloads on the desktop build.
